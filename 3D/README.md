# MRST-Based Simulation Codes

This repository contains MATLAB codes developed based on the MATLAB Reservoir Simulation Toolbox (MRST).  
The codes were developed and tested using **MRST-2023a**.

## Requirements

Before running the codes, please make sure the following software is installed:

- MATLAB
- MRST  
  These codes are based on **MRST-2023a**, but other MRST versions may also work.

## Download MRST

MRST can be downloaded from the official SINTEF website:

https://www.sintef.no/projectweb/mrst/download/

It is recommended to use **MRST-2023a** to ensure compatibility with the codes in this repository.

## Installation

1. Download MRST from the official website.
2. Extract the MRST package to a local folder.
3. Navigate to the folder containing the startup.m file.
4. Run this file from MATLAB or Octave.

startup.m should be run each time you start a new MATLAB / Octave session.
